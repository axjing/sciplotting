# 流程/机制/装置图排版符号与布局规范 (Diagram Specifications)

科研机制图、工作流程图与实验装置图是论文中最考验视觉传达效率的配图类型。国际顶刊推崇“极简、准确、逻辑自洽”的设计美学。本规范为示意图的图层组织、符号语法、排版几何与字体规范提供标准化准则。

---

## 1. 三层视觉信息架构 (3-Layer Information Hierarchy)

顶刊机制图最忌讳“信息平铺”导致视觉迷失。必须通过明度与对比度构建严格的 3 层视觉递进：

```
+-------------------------------------------------------------------+
| 第 1 层：物理边界与解剖背景 (Canvas & Boundaries)                |
|  - 纯白背景 (#FFFFFF) 或极浅微灰 (#F8F9FA)                       |
|  - 细胞质/细胞核轮廓：低饱和超浅底色 (#F0F4F8 / #EBF2FA)         |
|  - 细胞膜：脂质双分子层或双实线 (#CBD5E1, 1.0 pt)                |
+---------------------------------+---------------------------------+
                                  |
                                  v
+---------------------------------+---------------------------------+
| 第 2 层：常规元件与上下文参与者 (Actors & Intermediate Carriers)  |
|  - 非核心激酶、接头蛋白、细胞器、受体支架                        |
|  - 造型克制：圆角平整节点，无多余立体浮雕                        |
|  - 配色统一：使用低饱和中性色 (#94A3B8 / #64748B)                |
+---------------------------------+---------------------------------+
                                  |
                                  v
+---------------------------------+---------------------------------+
| 第 3 层：核心靶点与突破性机制 (Focal Targets & Novel Mechanism)   |
|  - 论文核心发现的分子、突变位点、药物抑制位点                    |
|  - 视觉锚点：唯一高亮主色 (如珊瑚红 #E15759 或天青蓝 #4E79A7)    |
|  - 动态状态标注：磷酸化黄色小球 (P)、泛素化分支链 (Ub)           |
+-------------------------------------------------------------------+
```

## 2. 机制图箭头语义语法 (Universal Arrow Grammar)

示意图中的所有连线与箭头必须具备严谨的生物物理或生化语义，严禁随意滥用箭头样式：

| 语义类型 | 符号表现 | 线型与端点 | 应用场景 |
| :--- | :--- | :--- | :--- |
| **直接激活 / 催化** | `───▶` | 实线 (1.0 pt) + 锐角实心三角箭头 | 激酶磷酸化底物、配体激活受体、酶促底物转化 |
| **直接抑制 / 阻断** | `───┤` | 实线 (1.0 pt) + 垂直平头短横杠 (T-Bar) | 拮抗剂阻断通道、抑制剂灭活酶、miRNA 降解靶 mRNA |
| **间接 / 多步级联** | `- - -▶` | 虚线 (1.0 pt, dash 4 2) + 箭头 | 跨细胞多步骤转导、推测但未完全证实的机制 |
| **间接抑制** | `- - -┤` | 虚线 (1.0 pt) + 垂直平头横杠 | 远端表型负反馈、经由中间介质的代偿抑制 |
| **易位 / 跨膜转运** | `~~~>` | 平滑曲线弯箭 (Curved Arrow) | 受体内吞、转录因子入核、囊泡胞吐外泌 |
| **物理结合 / 复合体** | `════` | 双实线或紧密贴合接触 | 异源二聚体组装、支架蛋白多分子复合物 |
| **转录启动** | `└──▶` | 直角转折折线箭头（转录起始位点 TSS） | 启动子启动下游靶基因 mRNA 表达 |
| **降解 / 切割** | `──⚡──` | 穿刺闪电符号或断裂虚线 | 蛋白酶水解多肽链、泛素-蛋白酶体降解靶标 |

## 3. 标准化生物与工程组件图元库

### 3.1 细胞膜系统
- **脂质双分子层 (Lipid Bilayer)**：亲水头部绘制为直径 3-4 mm 的圆形小球（充填 #94A3B8），两条疏水尾部以 0.5 pt 弯线向内指向。
- **跨膜蛋白 (Transmembrane Protein)**：以穿透双层脂质的圆柱体或 7 次跨膜折叠波浪线呈现，嵌入处平整贴合。

### 3.2 信号分子与修饰
- **激酶/酶活性中心**：圆角矩形（长宽比 1.6:1）或一侧略有凹陷的咬合构型。
- **翻译后修饰小球 (PTM Tags)**：
  - 磷酸化（Phosphorylation）：黄色小圆球 `#F28E2B`，内嵌白色或黑色粗体大写字母 **P**（字号 5 pt）。
  - 泛素化（Ubiquitination）：浅紫色圆球 `#9467BD`，内嵌 **Ub**。
  - 乙酰化（Acetylation）：绿色圆球 `#59A14F`，内嵌 **Ac**。
  - 甲基化（Methylation）：蓝色圆球 `#4E79A7`，内嵌 **Me**。

### 3.3 核酸与基因表达
- **DNA 双螺旋**：以两条连续交织的正弦曲线带表示，外轮廓 0.8 pt。
- **启动子区域与外显子**：
  - 启动子（Promoter）：前置方块标注 `Promoter / Enhancer`。
  - 外显子（Exon）：带有右向箭头的粗长方形条带，内标基因名。

### 3.4 实验装置与微流控
- **微通道 (Microchannels)**：内壁清晰单线或双线（0.8 pt），液流方向每隔适度距离标注细小单向箭头。
- **阀门与泵 (Valves & Pumps)**：标准气动阀以微小半圆或十字截断块表示。

## 4. 排版网格与几何对齐规范

1. **阅读流向 (Reading Trajectory)**：
   - 遵循自左向右（Left-to-Right）、自上而下（Top-to-Bottom）的天然认知规律。
   - 生物机制：`胞外刺激 (左/上) ➔ 膜受体 ➔ 胞质级联 (中) ➔ 细胞核转录 (右/下) ➔ 表型功能`。
2. **基底对齐与间距**：
   - 所有横向排列的同级节点（如一组平行下游效应靶点）强制启用 **顶端对齐 (Top Align)** 或 **水平中心对齐 (Center Align)**。
   - 节点之间的间距保持恒定（推荐 8 mm 或 12 mm 网格倍数）。
3. **连线避免交叉**：
   - 重新规划节点拓扑顺序，确保信号线交叉数量最小化；
   - 若无可避免，必须在连线相交处绘制微小跨线桥（Bridge）或使用虚线区分层级。

## 5. 示意图文本排版规范 (Typography in Schematics)

- **生物命名大小写规则**：
  - 人类基因名：全大写斜体（如 *TP53*, *EGFR*, *KRAS*）。
  - 人类蛋白质名：全大写正体（如 p53, EGFR, KRAS）。
  - 小鼠/啮齿类基因名：首字母大写其余小写斜体（如 *Trp53*, *Egfr*）。
  - 小鼠/啮齿类蛋白质名：首字母大写其余小写正体（如 Trp53, Egfr）。
- **字号阶梯**：
  - 区域划分大标题（如 `Extracellular Space`、`Nucleus`）：**7 – 8 pt 灰色全大写**。
  - 关键蛋白/酶名称：**7 – 8 pt 半粗体 (Semibold)**。
  - 辅助说明与修饰文字：**5.5 – 6.5 pt 常规体**。
